# Readme

## 要点汇总

-   **数据清理**：修正了绝大部分数据错误，主要是日期错误与时制不分，删除了2条上床时间在凌晨6点以后，且上床时间和准备入睡时间间隔超过2小时的数据
-   **各变量计算方式**：
    -   上床时间（bed time）：对应问卷中“您昨晚大致什么时间上床？”
    -   准备入睡时间（prepare to sleep
        time）：对应问卷中“您昨晚什么时候开始尝试入睡的？”
    -   入睡潜伏期（sleep latency）：对应问卷中“您花了多长时间入睡？”
    -   睡眠时长（total sleep time）：对应问卷中“您昨晚睡了多长时间？”
    -   睡眠拖延时间（night procrastination time）：准备入睡时间 -
        上床时间
    -   睡着时间点（sleep onset）：准备入睡时间 + 入睡潜伏期
    -   起床时间（wake up time）：睡着时间点 + 睡眠时长 - 24小时
-   **有趣的信息：**
    -   周中和周末的上床时间点、总睡眠时长、起床时间点有显著差异，但实际上准备睡觉的时间、睡眠潜伏期、和睡眠拖延时间没有显著差异。这说明**同学们可能主要是通过晚起来补觉，而不是通过提前准备睡觉来增加睡眠时长**
    -   无论是分周中周末，还是总体上看，都有**超过一半**的同学睡眠时长不足7小时
    -   在周中，睡眠在9小时以上的同学占比仅为6.54%，而在周末，**睡眠在9小时以上的同学占比超过了20%**，说明同学们还是有意识地在周末补觉
    -   在准备睡觉时间上，在周中约有20%同学在两点后上床，但在**周末升到了30%**
    -   社会性时差约为0.78小时（46.8分钟）
